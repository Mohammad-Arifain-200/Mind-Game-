# 🧠 Mind Game - Memory Card Game

A fun and interactive Memory Card Game built with HTML, CSS, and JavaScript.

The goal of the game is to find all matching emoji pairs using the fewest moves and in the shortest possible time.

## 🎮 Features

- 🃏 16 interactive cards
- 🔀 Random card shuffling
- 🧠 Match the same emoji pairs
- 🔢 Move counter
- 🏆 Score system
- ⏱️ Real-time game timer
- 🎉 Win message
- 🔄 Restart game option
- 📱 Responsive design
- ✨ Interactive card animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- CSS Grid
- JavaScript Array Methods
- setInterval()
- Event Listeners

## 🎯 How to Play

1. Click on any card to reveal the emoji.
2. Click on another card.
3. If both emojis match, the pair remains open.
4. If they don't match, the cards will flip back.
5. Continue until all pairs are matched.
6. Try to complete the game with fewer moves and less time.
